Política de Privacidade

Aplicativo: Content Factory — Ferramenta de Automação de Conteúdo
Última atualização: 27 de setembro de 2026

1. Sobre este aplicativo

O Content Factory é uma ferramenta de automação interna desenvolvida para uso exclusivo do titular da conta. Ela automatiza a geração e publicação de vídeos curtos em plataformas de mídia social, incluindo o TikTok, utilizando a TikTok Content Posting API.

Este aplicativo não é disponibilizado ao público em geral e não possui processo de cadastro ou login para terceiros.

2. Dados coletados

O aplicativo acessa, de forma limitada e exclusiva, os seguintes dados através da TikTok API:

  • Token de acesso OAuth: utilizado exclusivamente para autenticar requisições de publicação de vídeo na conta do titular.
  • Metadados de publicação: título, descrição e hashtags dos vídeos gerados internamente pelo próprio sistema.

O aplicativo não coleta dados de perfil, seguidores, comentários, mensagens, curtidas, histórico de visualizações ou qualquer outro dado pessoal do TikTok além do necessário para publicação.

3. Uso dos dados

Os dados acessados são utilizados exclusivamente para:

  • Autenticar e publicar vídeos na conta TikTok do titular do aplicativo.
  • Verificar o status da publicação após o envio.

Os dados não são utilizados para análise de comportamento, marketing, publicidade, venda ou compartilhamento com terceiros.

4. Armazenamento e retenção

O token de acesso OAuth é armazenado de forma segura no servidor privado do titular (VPS), protegido por autenticação e acessível apenas ao proprietário. Nenhum dado do TikTok é armazenado em bancos de dados de terceiros ou serviços de nuvem pública.

Os tokens são renovados automaticamente e os tokens antigos são descartados imediatamente após a renovação.

5. Compartilhamento com terceiros

Nenhum dado pessoal ou dado obtido via TikTok API é compartilhado, vendido, licenciado ou transferido a terceiros, incluindo parceiros comerciais, anunciantes ou prestadores de serviço externos.

6. Segurança

O acesso ao servidor e aos tokens é protegido por:

  • Autenticação SSH com chave criptográfica.
  • Comunicação exclusivamente via HTTPS/TLS.
  • Acesso restrito ao titular do aplicativo.

7. Direitos do usuário (LGPD)

Em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), o titular tem direito a:

  • Revogar o acesso do aplicativo à conta TikTok a qualquer momento, diretamente nas configurações de privacidade do TikTok.
  • Solicitar a exclusão de quaisquer dados retidos pelo sistema.

Para revogar o acesso: TikTok → Configurações → Privacidade → Aplicativos Conectados → remover "Content Factory".

8. Cookies e rastreamento

Este site e este aplicativo não utilizam cookies, pixels de rastreamento, Google Analytics ou qualquer outro mecanismo de rastreamento de usuários.

9. Alterações nesta política

Eventuais alterações serão publicadas nesta página com a data de atualização revisada. O uso continuado do aplicativo após alterações constitui aceite das novas condições.

10. Contato

Privacy Policy (English)

Application: Content Factory — Content Automation Tool
Last updated: September 27, 2026

1. About this application

Content Factory is an internal automation tool developed for the exclusive use of the account holder. It automates the generation and publication of short-form videos on social media platforms, including TikTok, using the TikTok Content Posting API.

This application is not available to the general public and has no sign-up or login process for third parties.

2. Data accessed

The application accesses, in a limited and exclusive manner, the following data through the TikTok API:

  • OAuth access token: used solely to authenticate video publishing requests on the account holder's behalf.
  • Publication metadata: title, description, and hashtags of videos generated internally by the system itself.

The application does not collect profile data, followers, comments, messages, likes, viewing history, or any other personal TikTok data beyond what is necessary for publishing.

3. Use of data

Accessed data is used exclusively to:

  • Authenticate and publish videos to the account holder's TikTok account.
  • Verify the publication status after submission.

Data is not used for behavioral analysis, marketing, advertising, sale, or sharing with third parties.

4. Storage and retention

The OAuth access token is stored securely on the account holder's private server (VPS), protected by authentication and accessible only to the owner. No TikTok data is stored in third-party databases or public cloud services.

Tokens are automatically refreshed and old tokens are immediately discarded after renewal.

5. Third-party sharing

No personal data or data obtained via the TikTok API is shared, sold, licensed, or transferred to any third party, including business partners, advertisers, or external service providers.

6. Security

Server and token access is protected by:

  • SSH authentication with cryptographic keys.
  • Exclusively HTTPS/TLS communication.
  • Access restricted to the application owner.

7. User rights

The account holder may revoke the application's access to the TikTok account at any time, directly in TikTok's privacy settings: TikTok → Settings → Privacy → Connected Apps → remove "Content Factory".

8. Cookies and tracking

This website and application do not use cookies, tracking pixels, analytics tools, or any user tracking mechanism.

9. Changes to this policy

Any changes will be published on this page with a revised update date.

10. Contact

For questions or requests related to this policy:
